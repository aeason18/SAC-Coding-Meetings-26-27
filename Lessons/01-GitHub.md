# Lesson 01: How to use GitHub

Once you have GitHub Desktop installed, you should be on this menu:

![GHD_start](https://github.com/aeason18/SAC-Coding-Meetings-26-27/blob/main/Images/GHD_start.png)

Select *Clone a repository from the internet...* and paste this link in: https://github.com/aeason18/SAC-Coding-Meetings-26-27/tree/main <br>

If you are returning and already have GitHub Desktop, you will see something like this: 

![GH Desktop](https://github.com/aeason18/SAC-Coding-Meetings-26-27/blob/main/Images/GH%20Desktop.png)

Just click on the current repo in the top left, then select Add -> Clone Repo -> URL and paste in the same link. <br>

Once you are here, these are the two main buttons you will use. The first, *Fetch Origin*, is used to pull any updates to the online repo to the one on your computer. The other one simply opens the repo in VS Code. 

![GHD_red](https://github.com/aeason18/SAC-Coding-Meetings-26-27/blob/main/Images/GHD_red.png)
